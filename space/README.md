Wolof, French, and English bus routes for Dakar.
Ask by text or voice; Koumba checks bus lines, transfers, and bus photos.
It downloads the public TIJAANI/dakar-bus-network dataset on first use.
The agent is Muse Spark Open; voice uses Meta Omnilingual ASR and Oolel-Voices.
No live traffic, schedules, or fares.

[Source code on GitHub](https://github.com/chniang/koumba)
